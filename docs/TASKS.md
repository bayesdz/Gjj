## 1. Договорённости, чтобы не мешать друг другу

### Структура проекта

```
Assets/_Game/
  Scripts/
    Core/        Nariman   GameEvents, GameState, MercyCounter, SceneFlow
    Player/      Nariman   контроллер, взаимодействие
    Combat/      Nariman   урон, здоровье, атака
    Enemies/     Nariman   поведение врагов, пощада
    Truth/       Nariman   Око истины (визуальная часть)
    AI/          Абу       LlmClient, GlasService, NpcDialogue, LineDatabase
    UI/          Nariman (логика) + Баха (вид)
  Data/
    Lines/       Мади      реплики Гласа, правды и запасные тексты (JSON)
    Characters/  Мади      карточки персонажей для ИИ (JSON)
  Art/           Баха      модели, материалы, текстуры, VFX
  Audio/         Баха      музыка, звуки
  Scenes/
    Sandbox_Nariman.unity  личные тестовые сцены:
    Sandbox_Abu.unity      каждый правит только свою
    Sandbox_Baha.unity
```

**Правило сцен:** одну сцену правит один человек. Общие объекты делаются префабами.

### Связь модулей через события (`Core/GameEvents.cs`, пишет Nariman)

```csharp
public static class GameEvents
{
    public static event Action<string> EnemySpared;      // enemyId
    public static event Action<string> EnemyKilled;      // enemyId
    public static event Action<string> ItemInspected;    // itemId
    public static event Action<bool>   EyeToggled;       // включено/выключено
    public static event Action<string> NpcTalked;        // npcId
    public static event Action<string> GlasDisobeyed;    // momentId
    public static event Action<string> NarrationRequest; // ключ реплики, например "floor1.goblin_first_seen"
}
```

Геймплей только **вызывает** события. ИИ-модуль Абу и счётчик милосердия только **слушают** их. Так Nariman и Абу работают параллельно и не трогают код друг друга.

### Интерфейс ИИ-модуля (пишет Абу)

```csharp
public interface IGlas
{
    // Реплика Гласа (ложь). При ошибке или тайм-ауте возвращает запасной текст.
    Task<string> Narrate(string lineKey, string context);
    // Правдивая версия той же сцены для Ока истины.
    Task<string> Truth(string lineKey, string context);
    // Свободный диалог с NPC: история разговора хранится внутри.
    Task<string> Ask(string npcId, string playerText);
}
```

**Правило ИИ:** любой вызов имеет тайм-аут 3–5 секунд. Если ответа нет, сразу показываем запасной текст. Игра никогда не ждёт сеть.

### Формат реплик (`Data/Lines/*.json`, пишет Мади, читает Абу)

```json
{
  "key": "floor1.goblin_first_seen",
  "lie": "Осторожно! Эти твари нападают из темноты. Не давайте им шанса.",
  "truth": "Гоблин-подросток держит ржавый нож. Он дрожит: за ним вход в пещеру, где спят младшие.",
  "hint": "Глас запугивает, правда показывает, что гоблин защищает семью",
  "secret_word_slot": false
}
```

`lie` и `truth` — запасные тексты. ИИ по `hint` и контексту генерирует свою вариацию.

### Карточка персонажа (`Data/Characters/*.json`)

```json
{
  "id": "ogre_chief",
  "name": "Огр-вождь",
  "persona": "Старый, усталый, говорит коротко и тяжело",
  "knows": ["Сияющие — слуги богини", "Его сын прячется в крепости"],
  "never": ["Не выходит из роли", "Не знает про реальный мир и ИИ"],
  "fallback_answers": ["Уходи. Пока ты ещё можешь выбрать.", "Посмотри на стены. Там наша история."]
}
```

## 6. Как работаем

- **Созвон 15 минут каждый день** в одно и то же время: что сделал, что делаю, где застрял.
- **Git:** перед работой `pull`, коммиты маленькие и частые, в конце дня `push`. Сообщение коммита начинается с ID задачи: `N4: hit feedback`.
- **Застрял больше часа** → пишешь в чат команды, не сидишь молча.
- **Заготовка ≤ 50%:** до джема делаем только системы и тестовые сцены. Уровни, финальный арт и реплики с секретными словами делаем на джеме.

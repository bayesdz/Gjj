## 1. Подключение к проекту (Абу и Баха — сегодня, Мади — по желанию)

1. Поставить **Git** (git-scm.com, всё по умолчанию).
2. Поставить **Unity Hub** и через него **ровно Unity 6000.3.29f1** (Установки → Установить редактор → Архив, если в списке нет). Модули не нужны. Visual Studio ставить не обязательно: хватит VS Code с расширением Unity.
3. Склонировать проект:
   ```bash
   git clone https://github.com/bayesdz/Gjj.git
   ```
   ```bash
   cd Gjj && git checkout claude/vibrant-edison-tsjz3h
   ```
4. Unity Hub → «Добавить» → «Добавить проект с диска» → папка `Gjj`. Первое открытие идёт 5–10 минут.
5. Меню **False Paradise → Build Sandbox Scene** → **Play**. Если всё работает, ты в проекте.

**Правила работы в Git:**
- Перед началом работы — `git pull`, в конце дня — `git add -A`, `git commit -m "ID: что сделал"`, `git push`.
- Каждый правит **только свою** песочницу: `Sandbox_Nariman`, `Sandbox_Abu`, `Sandbox_Baha`. Чужие сцены не сохранять.
- Общие объекты (враги, предметы, UI) — только через префабы в своей папке.
- Каждый внешний ассет сразу записывается в `docs/ASSETS.md`.
- Застрял больше часа — пишешь в чат команды.

**Созвон 15 минут каждый день в 21:00:** что сделал, что делаю, где застрял.

## 3. Абу — ИИ-модуль (Глас, Око, диалоги)

### Как устроено

Геймплей ничего не знает про ИИ. Он только вызывает события из `GameEvents`, например `NarrationRequest("z1.goblin_first_seen")`. Твой модуль подписывается на них, получает текст (от ИИ или запасной) и показывает его через `GameHUD.ShowSubtitle(кто, текст, секунды)`.

Все файлы — в `Assets/_Game/Scripts/AI/`, тестовая сцена — `Sandbox_Abu.unity`.

### Формат реплик (`Assets/_Game/Data/Lines/zone1.json`)

```json
[

    "key": "z1.goblin_first_seen",
    "lie": "Осторожно! Эти твари нападают из темноты. Не давайте им шанса.",
```

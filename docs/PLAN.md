## Риски

- **ИИ не отвечает у жюри** → запасные реплики, игра проходится полностью без сети.
- **API-ключ в билде можно достать** → лимит расходов, после 20 декабря ключ отозвать.
- **Конфликты сцен в Git** → одну сцену правит один человек, остальные работают в префабах.
- **Не успеваем** → режем по порядку: реплики друзей через ИИ → свободный диалог с огром-кузнецом (остаётся с вождём) → бой со Стражем (Око выдают сразу).

# FALSE PARADISE

Dark fantasy dungeon RPG от первого лица для **Dungeon GameJam SU 2026** (тема «Магия ИИ в фэнтези мире»).

Героя ведёт по подземелью **Глас** — заботливый ИИ-рассказчик, который лжёт. Амулет **Око истины** показывает вторую, правдивую версию того же мира. Игрок сам решает, кому верить, кого щадить и кем он стал.

- Сюжет: [`docs/STORY.md`](docs/STORY.md)
- План подготовки и джема: [`docs/PLAN.md`](docs/PLAN.md)
- Задачи по людям: [`docs/TASKS.md`](docs/TASKS.md)
- Внешние ассеты и лицензии: [`docs/ASSETS.md`](docs/ASSETS.md)

## Технологии

- Unity 6 LTS, шаблон Universal 3D (URP). Версия Unity у всей команды должна совпадать: она закреплена в `ProjectSettings/ProjectVersion.txt`.
- ИИ: облачная языковая модель плюс офлайн-режим с заранее написанными репликами (и, по итогам проверки, локальная модель через LLMUnity).

## Запуск

1. Скачать архив билда из Releases.
2. Распаковать и запустить `FalseParadise.exe`. Устанавливать ничего не нужно, игра проходится и без интернета.

## Правила репозитория

- API-ключи не коммитим никогда (`.env` в `.gitignore`).
- Файлы локальных моделей (`*.gguf`) не коммитим, их скачивают отдельно.
- Каждый внешний ассет сразу записываем в `docs/ASSETS.md`.
- Одну сцену одновременно правит один человек. Остальные работают в префабах.
